# Плоское ребро: расчёт Q̇ и η_f по численным данным T(x)

Портативное Windows-приложение (tkinter, только стандартная библиотека
Python 3.9+) для расчёта мощности теплоотдачи **Q̇** и эффективности
**η_f** плоского прямоугольного ребра по численному профилю температуры
T(x) из `.dat`-файлов (выгрузки КОРСАР/GraphLab).

## Физическая модель

Плоское ребро ширины `b` и высоты охлаждаемой части `L`. Обе широкие
поверхности охлаждаются воздухом при температуре `T1` с коэффициентом
теплоотдачи `α`. Охлаждаемый периметр `P = 2b`, площадь теплоотдачи
`A_f = P·L = 2bL`. Торец (x = L) и узкие кромки изолированы.

Вычисляемые величины:

| Величина | Формула | Единицы |
|---|---|---|
| `I` | ∫[0..L] (T(x) − T1) dx (трапеции + краевые заплатки) | К·м |
| `Q̇` | α · P · I | Вт |
| `η_f` | I / (L · (T0 − T1)) = Q̇ / (α·A_f·(T0−T1)) | — (от α не зависит) |
| `M` | подгонка θ(x) = A·cosh[M·(1 − x/L)] (А — НМК, M — золотое сечение на [0.05, 20]) | — |
| `η_analytic` | tanh(M)/M | — |

Приложение **не** решает задачу теплопроводности: `λ` и `δ` не требуются.

## Запуск из исходников

```bat
python fin_q_eta_calculator.py
```

Для запуска двойным кликом без консоли переименуйте файл в
`fin_q_eta_calculator.pyw` (Windows автоматически запустит его через
`pythonw.exe`).

Никаких дополнительных пакетов не требуется: только `math`, `pathlib`,
`tkinter` из стандартной библиотеки.

## Использование

1. Введите параметры: `b`, `L`, `α`, `T0` и `T1` (температуры в °C,
   рядом live-отображаются значения в Кельвинах; расчёт ведётся в К).
2. Выберите два **раздельных** `.dat`-файла:
   - файл с `x` (строка начала данных, дефолт 1);
   - файл с `T` (строка начала данных, дефолт 4 — рекомендуется для
     GraphLab: данные начинаются после заголовка и нулевого ряда).
3. Нажмите **«Рассчитать»** — результаты появятся в блоке «Результаты»,
   подробности — в блоке «Лог».
4. Кнопка **«Сохранить отчёт…»** пишет текстовый отчёт `.txt` (UTF-8).

### Формат входных .dat-файлов

- одно число на строку; лишние значения в строке допустимы — берутся
  по порядку (поддерживается перенос длинных логических строк GraphLab
  на несколько физических строк);
- разделители: пробел, табуляция, запятая, точка с запятой;
- пустые строки игнорируются; комментарии `#`, `%`, `//` — тоже;
- нечисловые заголовки пропускаются (цифры внутри слов, например
  «LAB9», в значения не попадают);
- числа в обычном и научном формате: `0.01`, `1e-3`, `-2.5`, `+3.14`;
- NaN/inf пропущены с предупреждением;
- при несовпадении количества значений x и T используется минимальное
  количество пар (предупреждение в логе).

### Интеграл: краевые заплатки

- основная часть — метод трапеций на [x_min, x_max];
- если x_min > 0 — добавляется трапеция на [0, x_min] с T(0) = T0;
- если x_max < L — добавляется трапеция на [x_max, L] с T(L) = T(x_max)
  (адиабатический торец: dT/dx|_L = 0).

Вклады заплаток выводятся в лог и в отчёт.

### Валидация и особые случаи

- `b`, `L`, `α` — конечные числа, строго > 0;
- точки с x вне [0, L] больше чем на tol = 1e-9·L исключаются (предупреждение);
- минимум 2 пары данных;
- если |T0 − T1| < 1e-12: Q̇ = 0, η_f показывается как «—», предупреждение;
- если первая точка профиля отличается от T0 больше чем на 1 К — предупреждение;
- если относительный остаток подгонки M > 5 % — предупреждение (значения всё равно выводятся).
